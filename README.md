## 机房与线路：先确定用户在哪，再谈快不快

机房位置决定物理延迟的下限，线路决定这个下限能不能兑现。国内访问美国的实测经验值是：西海岸优化线路 150–180ms 算优秀，西海岸普通线路 190–230ms 属正常，超过 250ms 基本可以怀疑绕路了。同样的机器放东海岸，普遍比西海岸再高出 50ms 以上。用户在欧洲或北美，这条规则就反过来用，机房要靠近客户而不是靠近你自己。

线路这块，CN2 GIA 走中国电信 59.43 段独立路由，有 QoS 保障，回国延迟通常能压到 160–180ms，晚高峰相对稳；普通线路走 163 骨干或 AS4837，延迟普遍落在 190–250ms，晚高峰容易出现拥堵和丢包。代价是 CN2 GIA 的带宽成本更高，同配置报价通常比普通 BGP 贵三到五成。用户主要在国内，这笔钱花得值；用户主要在欧美，普通线路完全够用，省下来的钱投到别处更划算。

Evoxt 目前公开可查的节点包括香港、日本大阪和吉隆坡，其中香港、大阪、吉隆坡走的是优质网络线路。2026 年 6 月一份针对大阪节点的第三方测评给出了一组有用的细节：机房使用自有 ASN（AS149440）加多上游接入，回程为 SoftBank 方案，电信去程走 163 骨干接 SoftBank，移动走 CMI 经香港落地大阪，联通去程绕经欧洲再跨美，延迟明显偏高。也就是说，**电信和移动用户用大阪节点体验较好，联通用户要谨慎**。同一次测评中，VM-0.5 分配到了 IPv4 与 IPv6 双栈地址，端口标称 1Gbps，IP 风险评分处于低风险区间，Netflix、Disney+、YouTube、TikTok、ChatGPT 均可解锁。

这份测评反映的是单节点、单机型的情况，香港和吉隆坡的实际表现会有差异，选之前最好自己 ping 一轮。

**访客几乎全在国内、对延迟极敏感的主站。** 香港节点和优质的日本节点能缓解，但如果你的核心指标是国内三网稳定压在 160ms 以内，走 CN2 GIA 的国内商家在路由调优上更专注，可选的高防和大带宽方案也更成熟。

**需要支付宝、微信直接付款的。** 官网已核验的购买页只列出了信用卡与借记卡通道，其他支付方式在页面上没有确认。如果你没有外币卡，付款这一步就会卡住。

**必须先确认退款条款再下单的。** 本次核验的官网价格页与产品页均未列出退款期限或免费试用说明，习惯“先试后买”的人需要先发工单问清楚。

## 下单前常被问到的几个问题

**国外服务器需要备案吗？**
不需要。服务器在境外，不受工信部备案约束，开通即可部署。但免备案不等于什么都能放，机房所在地的法律法规照样管，违规内容被投诉一样会封机器，这一点和国内没有区别。

**延迟多少算正常？**
国内访问香港节点，正常情况下几十毫秒；日本节点通常在一百毫秒上下；美国西海岸优化线路 150–180ms 属于优秀，普通线路 190–230ms 是常态。超过 250ms 就要查一下路由是不是绕了。

**带宽和流量是一回事吗？**
不是。带宽是瞬时速率上限，流量是一个月能传多少数据。Evoxt 的套餐按月流量配额计，超了需要看官方后续处理方式，下单前建议确认；市面上另有一类产品是限带宽但不限流量，比如 5Mbps 配无限流量，跑小站够用但撑不起并发。

**能装 Windows 吗？**
可以。官方镜像列表包含 Windows 远程桌面，同时也提供 Linux 各发行版。Windows 授权是否含在套餐价内，下单页会写明，别默认包含。

**IP 被封了怎么办？**
Evoxt 的控制台支持在服务器之间换绑和重新分配 IP，也能额外订购浮动 IP。这个能力在跑爬虫、多账号管理这类业务时比多给 1GB 内存实用得多。

**以后配置不够能升级吗？**
可以。官方建议不确定时从最小套餐开始，业务增长后再往上调。

**支持支付宝或微信吗？**
已核验的官网购买页只列出信用卡与借记卡通道，支付宝和微信没有确认支持。结账页会显示完整选项，没有外币卡的用户要在这一步先确认。

**有退款和试用吗？**
官网价格页与产品页没有列出退款期限和免费试用政策。VM-0.5 月付 $2.99，用一个月验证线路的成本大约是一杯咖啡，比走退款流程更省事。
